# FRC Team 31 -- 2026 Competition Robot

## Overview
WPILib command-based robot (Java 17, Gradle). Season: 2026. Build system: GradleRIO `2026.2.1`.
The mascot is **Mango Bird**. A custom ASCII Mango Bird prints on every Gradle build.

## Key Libraries
| Library | Purpose |
|---|---|
| **AdvantageKit** | Logging + replay. All subsystems use `@AutoLog` inputs. |
| **PathPlanner** | Autonomous path following + `AutoBuilder` named commands |
| **CTRE Phoenix 6** | Drive/steer/turret/climb motors (TalonFX, CANcoder, Pigeon2) |
| **REVLib** | (vendordep present, check for specific motors) |
| **PhotonVision** | AprilTag pose estimation |
| **Limelight** | AprilTag + game piece targeting |
| **WPILib NewCommands** | Command-based framework |

## Naming Conventions
- **Private fields**: `_underscoredCamelCase` (e.g., `_turret`, `_gyroInputs`)
- **Public fields/constants classes**: `PascalCase` (e.g., `Kinematics`, `AutoChooser`)
- **Constants**: `SCREAMING_SNAKE_CASE` (e.g., `FLYWHEEL_MAX_SPEED`, `TURRET_GEAR_RATIO`)

## IO Abstraction Pattern (Critical)
Every hardware subsystem splits into **Interface -> Real -> Sim** + an `Inputs` class:

```
subsystems/turret/
├── ITurret.java          ← interface (hardware methods)
├── TurretReal.java       ← real robot implementation
├── TurretSim.java        ← simulation implementation
├── TurretInputs.java     ← @AutoLog annotated inputs struct
└── Turret.java           ← WPILib Subsystem (holds IO + inputs, exposes commands)
```

The subsystem class calls `io.updateInputs(inputs)` then `Logger.processInputs(...)` every periodic.

## Swerve Details
- **Chassis**: 24.75" square, max speed 5.4 m/s
- **Module layout**: FL / FR / RL / RR -- CAN IDs and offsets in `SwerveModuleMap.java`
- **Gyro**: Pigeon2 (`GyroReal` / `GyroSim`)
- **Auto-align**: `AutoAlign.java` (turret targeting while driving)
- **Pathfinding**: `LocalADStarADK.java` (AKit-compatible wrapper)

## Container & Named Commands
`Container.java` wires all subsystems and registers **PathPlanner named commands**:

| Named Command | Action |
|---|---|
| `"Enable_Autonomous_Shooting"` | `toggleShooterOn()` |
| `"Disable_Autonomous_Shooting"` | `toggleShooterOff()` |
| `"Start_Auto"` | `startAuto()` |
| `"Take_Out_And_Enable_Intake"` | `toggleIntakeOn()` |
| `"Put_In_And_Disable_Intake"` | `toggleIntakeOff()` |
| `"Setup_Climb"` | `setupClimb()` |
| `"Climb"` | `startClimbing()` |
| `"Stop_Climb"` | `stopClimbing()` |

Auto paths live in `src/main/deploy/pathplanner/`. Auto selector built via `AutoBuilder`.

## SuperStructure
`SuperStructure.java` is a static class holding all `*InputsAutoLogged` instances:
- `SwerveSubsystemInputsAutoLogged`
- `HopperInputsAutoLogged`
- `TurretInputsAutoLogged`
- `ClimbInputsAutoLogged`
- Vision inputs (Limelight + Photon)
- Per-module `SwerveModuleInputsAutoLogged[4]`

## AdvantageKit Logging Modes
Configured in `Robot.java`:
- **REAL**: Logs to USB (`/U/logs`) + NetworkTables
- **SIM**: Logs to NetworkTables only
- **REPLAY**: Reads from a WPILOG file (use `replayWatch` Gradle task)

## Build & Deploy
```bash
./gradlew build          # Build (Mango Bird appears on success/failure)
./gradlew deploy         # Deploy to roboRIO (auto-commits if branch contains "autocommit")
./gradlew simulateJava   # Run simulation with GUI
./gradlew replayWatch    # Launch AKit log replay
./gradlew test           # JUnit 5 + Mockito tests
```

## Gradle Notes
- `gversion` generates `BuildConstants.java` (package `org.prime.util`) -- only on autocommit branches
- Desktop simulation support is **enabled** (`includeDesktopSupport = true`)
- Fat JAR bundles all deps; source/vendordeps backed up inside the jar under `backup/`

## Simulation
- `SwerveModuleSim`, `GyroSim`, `TurretSim`, `HopperSim`, `ClimbSim` provide sim-friendly implementations
- `wpi.sim.addGui()` and `wpi.sim.addDriverstation()` are enabled
- `simgui.json` / `simgui-ds.json` / `simgui-window.json` store sim GUI layout
